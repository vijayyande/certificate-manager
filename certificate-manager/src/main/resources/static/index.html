Certificate Profiles

Profiles bundle key algorithm, size, validity, key usage, extended key usage and key storage so requesters can pick one instead of entering every field. Built-in types (code signing, client, email, document signing, Class 1/2/3, Aadhaar eSign, ...) auto-fill the defaults; every field stays editable. CA profiles can only be used by administrators. Profiles with PKCS#11 key storage generate the key pair on the HSM at issuance and keep key + certificate on the device (no exportable key).

PKCS#11 device (HSM / smart card)

                
Connect a PKCS#11 device so CA private keys can be generated and kept on hardware, never leaving the token. When PKCS#11 is enabled, newly requested CAs can be issued with their key on the device; all signing (CA certs, leaf certs, CRLs, OCSP) then happens natively on the token.

Signed Audit Log

                
            

            
Every significant action is recorded in a tamper-evident chain: each entry hashes the previous one (SHA-256) and is signed with the platform audit secret (HMAC-SHA256), so any modification or reordering is detectable. Verify recomputes the whole chain from the database.
